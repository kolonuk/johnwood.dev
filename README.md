# johnwood.dev

Personal website and playground for John Wood.

## Overview

This is a simple PHP application designed to run on Google App Engine. It serves as a personal landing page and a demonstration of PHP 8.2 deployment on Google Cloud Platform.

## Technology Stack

- **Language:** PHP 8.2
- **Platform:** Google App Engine (Standard Environment)
- **Deployment:** GitHub Actions with Workload Identity Federation
- **Package Management:** Composer
